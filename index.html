Paste your secret access token to unlock your tracker on this device. You set this up once in Supabase — same token across all your devices.

First time setup? Read this.
  1. You should have already created a Supabase project and run the SQL schema.
  2. Your token is whatever random string you saved — paste it above.
  3. The token gets stored on this device only (localStorage). Never sent to GitHub, never in the URL.
  4. On a different device, you'll paste it once and it'll save there too.
  5. If you lose your token, your data is unreachable (this is by design).
